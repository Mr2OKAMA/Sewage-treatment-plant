# Sewage Treatment Plant

Three.js と PointerLockControls で作る、ブラウザ上で動くレトロホラー風の一人称視点ゲームです。
下水処理場を舞台に、電話で受けた指示に従って施設を探索します。準備を怠ると即死する場所がいくつもあります。

## プレイ

👉 **https://mr2okama.github.io/Sewage-treatment-plant/**

ブラウザで開き、画面をクリックすると開始します。Three.js は CDN（jsDelivr）から読み込むので、ネットワーク接続が必要です。

### ローカルで動かす場合

ES Modules を使っているため、`file://` ではなくローカルサーバーで開いてください。

```bash
npx serve
# または
python -m http.server
```

## 操作

| 操作 | 内容 |
| --- | --- |
| 画面クリック | ポインタロック開始（ゲーム開始） |
| `W` `A` `S` `D` | 移動 |
| マウス | 視点移動 |
| `F` | 懐中電灯の ON/OFF |
| `E` / 左クリック | インタラクト（電話に出る、アイテムを拾う、会話を進める） |
| `Esc` | ポインタロック解除 |

## ゲームの内容

### 描画・演出
- 解像度を下げて描画し、`image-rendering: pixelated` でドット感を出しています。
- 薄暗いフォグ（`FogExp2`）をかけています。
- カメラに追従する SpotLight が懐中電灯です。
- 画面中央に小さなクロスヘア（ドット）があります。

### インタラクト
- 画面中央からレイを飛ばし、3m 以内のインタラクト対象に焦点が合うと、クロスヘアが黄色になります。
- 「E: 電話に出る」「E: 拾う（ガス検知器）」のようなプロンプトが表示されます。
- 壁越しには反応しません。

### 固定電話
- 壁掛けの電話機が赤く点滅し、着信音が鳴ります。ポインタロック開始後に鳴り始めます。
- 電話に出ると画面が暗くなり、レトロな緑色のダイアログで、ベテラン社員の台詞が 1 文字ずつ表示されます。
- ダイアログ中は `E` またはクリックで、全文表示、次の台詞、終了の順に進みます。
- 通話中は移動できません。通話を終えるとチェックポイントが保存されます。

### アイテムとインベントリ
- 床に落ちている「ガス検知器」と「鍵」をインタラクトで拾います。
- 拾ったアイテムは `playerState.inventory` に追加され、画面右下に表示されます。

### ゲームオーバーと死亡図鑑
- 地下ピットへ続く階段エリアに、ガス検知器なしで入ると、硫化水素中毒で即死します（`DEATH_001`）。
- ゲームオーバーでは、暗転、画面シェイク、ノイズ音のあと、赤字で死因が表示されます。
- 死亡 ID は `localStorage`（キー `sewage_deaths`）に記録され、死亡図鑑に反映されます。未取得の死に方は伏せ字で表示されます。
- 「直前からやり直す」で、最後のチェックポイントに復帰します。所持品とフラグは保持されます。

## ファイル構成

```
index.html          HTML 構造、importmap、各種 UI 要素
style.css           クロスヘア、プロンプト、インベントリ、電話 UI、ゲームオーバー
js/
  app.js            Three.js の初期化、マップ構築、レンダーループ
  controls.js       PointerLockControls、WASD 移動、壁との当たり判定
  interaction.js    Raycaster によるインタラクト判定
  phone.js          PhoneUI（タイプライター表示のダイアログ）
  inventory.js      インベントリの追加と描画
  gameState.js      プレイヤー状態、進行フラグ、チェックポイント
  state.js          gameState.js の再エクスポート（後方互換）
  gameOver.js       triggerGameOver、死亡図鑑
  events.js         エリア進入イベントの判定
```

## 拡張方法

### 死に方を追加する
`js/gameOver.js` の `DEATHS` に追記し、`triggerGameOver('DEATH_00X', '死亡理由')` を呼びます。

```js
export const DEATHS = {
  DEATH_001: { no: '001', name: '硫化水素中毒' },
  DEATH_002: { no: '002', name: '...' },
};
```

### エリアイベントを追加する
`js/events.js` の `zones` に、`Box3` と `onEnter` を持つ項目を追加します。

### アイテムを追加する
`js/gameState.js` の `ITEM_NAMES` に ID と表示名を追加し、`js/app.js` で `spawnItem(id, color, x, z, size)` を呼びます。

### フラグを使う
`setFlag('pumpStopped', true)` や `getFlag('pumpStopped')` で、進行状況を管理します。
